Before you start

What you need

What's inside

  • Everything needed to run — no Python or extra tooling to install.
  • The memory and speech models, so it works offline from the first launch.
  • Automatic updates, which always ask before installing.

First launch

  • It takes a moment to prepare its database. That's normal.
  • A short assistant sets up language, model, voice and permissions.
  • Every step can be skipped and changed later.

Windows will warn you. Here's why, and what to do

Aithera is in beta and the installer is not signed with a code-signing certificate yet. Those are expensive and issued to registered companies, so early-stage software very often ships without one. When that's the case, Windows SmartScreen shows a blue "Windows protected your PC" screen for any program it hasn't seen many times before. It is not a virus detection — it's Windows saying it doesn't recognise the publisher.

  1. Run the installer you downloaded.
  2. When the blue screen appears, click More info.
  3. Click Run anyway.

If you'd rather check the file first, every release publishes the SHA-256 checksum of the installer on its release page. You can verify it in PowerShell before running anything:

Get-FileHash "$HOME\Downloads\Aithera Setup 1.5.1-3.exe" -Algorithm SHA256

Your antivirus may flag it for the same reason. If it does and you'd rather not continue, that's a perfectly reasonable choice — write to us and we'll help.

Your data

Aithera keeps everything on your machine. Uninstalling removes the program and its data. Optional, anonymous technical diagnostics can be turned off in Settings → General, and you can see exactly what would be sent before it goes. The details are in the Privacy Policy and the Terms of Use.
